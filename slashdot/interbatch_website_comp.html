About This Competition

SlashDot invites students across all batches to participate in the Inter-Batch Website Development Competition 2026. This competition focuses on visual design, programming quality, architecture, and storytelling through the web.

Beyond the competition, this initiative serves as a blueprint for SlashDot's future. The most innovative designs, architectural patterns, and user experiences from winning entries will be integrated into the Official SlashDot Website, giving you the unique opportunity to leave a permanent mark on the club's digital heritage.

All submitted websites and repositories will be visible to everyone, enabling community voting and fostering collaboration across batches.

🏆 Total Prize Pool: INR 4,500 📜 Participation certificates will be given to all participants!

Participation Guidelines
• Participation is open to BS-MS, RS, MR, MP, and IP students.
• RS, MR, MP, and IP fellows are encouraged to participate together as one batch.
• For BS-MS, maximum 2 teams per batch (e.g., two teams from 25MS).
• Maximum 20 participants per team. Each team submits one project.
• For more details, please check the detailed guidelines here.
• Submit entries via the official Google Form and host projects publicly on GitHub.

Project Hosting Requirements

GitHub Repository

Must include full source code, documentation, setup instructions, dependencies, and licensing information.

GitHub Pages Deployment

Live version deployed and accessible. Frontend must work fully on GitHub Pages.

Backend Setup (If Required)

Include clear setup instructions. Recommended: single setup script, Docker/Podman config, or automated dependency setup.

The README must allow judges to run your project with minimal setup effort.

Allowed Technologies

No restrictions! Use any framework or technology:

HTML / CSS / Vanilla JS React Vue Angular Svelte Next.js Astro Three.js WebGL WebAssembly Game Engines And more...

The emphasis is on creativity, code quality, and execution.

Mandatory Website Sections
• Homepage - Clear introduction to the website's purpose
• About/Concept Page - Explain your idea, theme, and narrative
• Tech Stack Page - Technologies used & architecture explanation
• Team Page - Introduce the creator(s)
• Contact Page - Functioning contact section or information
• Logos & Branding - Display IISER Kolkata and SlashDot logos (high-res files will be provided)

Theme & Creative Freedom

You have complete creative freedom! Possible themes include:

• Interactive storytelling websites
• Web-based games
• Interactive light novels
• Blogging platforms
• Personal portfolio websites
• Educational platforms
• Experimental web art
• Simulation websites
• Scientific visualizations
• Community platforms

Important: Clearly state your website's agenda and purpose in the project description and submission form.

Judging Criteria
Theme & Concept
Originality, clarity of objective, creativity & narrative
Design & UX
Visual aesthetics, UI quality, navigation, responsiveness
Technical Implementation
Code quality, architecture, modularity, maintainability
Performance
Loading latency, optimization, efficient asset usage
Content & Organization
Logical structure, documentation quality, readability
Innovation
Unique features, interactive elements, advanced technologies

Judging Panel
• Dr. Dwaipayan Roy - Internal Judge, IISER Kolkata
• External Judge - To be announced soon

Community Voting & Scoring

All submitted websites and repositories will be shared with the student body and faculty. A public voting process will determine the Audience Choice Award.

Scoring Breakdown: Average of internal and external judge scores determines the overall winners. The Audience Choice is determined entirely by public poll. The Most Innovative award is determined by a combination of judge scores and the public poll.
